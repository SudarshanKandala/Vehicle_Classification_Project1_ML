# Data files (not bundled)

Place these Kaggle-provided CSV files here before running the standalone script:

- `vehicle_train_10000(1).csv`
- `vehicle_test(1).csv`
- `vehicle_sample_submission(1).csv`

Dataset files are not included in this GitHub-ready package. Follow Kaggle competition terms before publishing or redistributing any data.

The test dataset is used **only after** model training to generate predictions; no EDA, preprocessing fitting, or hyperparameter tuning uses test features.
